# Technologies

- **Python**: 3.14+ (see `.python-version`)
- **Package manager**: `uv` (lockfile: `uv.lock`)
- **Linting/formatting**: Ruff (configured in `pyproject.toml`)
- **Pytest** for testing
- **Loguru** for logging
- **Selenium** and **BeautifulSoup** to scrape web pages and retrieve their content
